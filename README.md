## 📌 Sobre

Repositório com exercícios de lógica de programação resolvidos diariamente, vindos do [Beecrowd](https://www.beecrowd.com.br/) e [LeetCode](https://leetcode.com/), como parte da minha rotina de estudos para vagas de estágio em tecnologia.

## 🗂️ Estrutura

```
daily-coding-challenges/
├── arrays/
├── strings/
├── recursion/
├── math/
├── sorting-searching/
└── README.md
```

Cada pasta representa um tema. Dentro dela, um arquivo por exercício, nomeado como `NNN-nome-do-exercicio.ext` (ex: `001-soma-simples.java`).
