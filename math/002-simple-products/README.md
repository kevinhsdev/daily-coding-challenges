# ✖️ 1004 - Simple Product
 
![Beecrowd](https://img.shields.io/badge/Beecrowd-1004-blue)
![Status](https://img.shields.io/badge/status-Accepted-brightgreen)
 
## 📋 Enunciado
 
Read two integer values. After this, calculate the product between them and store the result in a variable named PROD. Print the result like the example below. Do not forget to print the end of line after the result, otherwise you will receive "Presentation Error".
 
## 📥 Input
 
O arquivo de entrada contém 2 valores inteiros.
 
## 📤 Output
 
Imprimir a mensagem `"PROD"` seguida do resultado, com um espaço em branco antes e depois do sinal de igual.
 
## 🧪 Exemplos
 
| Input | Output |
|-------|--------|
| 3<br>9 | PROD = 27 |
| -30<br>10 | PROD = -300 |
| 0<br>9 | PROD = 0 |
 
## 💡 Lógica utilizada
 
O valor de PROD é simplesmente a multiplicação direta entre os dois números lidos.
 
```
PROD = a * b
```
