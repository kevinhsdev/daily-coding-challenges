# 💰 1008 - Salary

![Beecrowd](https://img.shields.io/badge/Beecrowd-1008-blue)
![Status](https://img.shields.io/badge/status-Accepted-brightgreen)

## 📋 Enunciado

Write a program that reads an employee's number, his/her worked hours number in a month and the amount he received per hour. Print the employee's number and salary that he/she will receive at end of the month, with two decimal places.

Don't forget to print the line's end after the result, otherwise you will receive "Presentation Error". Don't forget the space before and after the equal signal and after the U$.

## 📥 Input

O arquivo de entrada contém 2 números inteiros (número do funcionário e quantidade de horas trabalhadas) e 1 valor de ponto flutuante (valor recebido por hora trabalhada).

## 📤 Output

Imprimir o número do funcionário e o salário, com um espaço em branco antes e depois do sinal de igual.

## 🧪 Exemplo

**Input**
```
25
100
5.50
```

**Output**
```
NUMBER = 25
SALARY = U$ 550.00
```

## 💡 Lógica utilizada

O salário é o resultado de horas trabalhadas × valor por hora, formatado com 2 casas decimais.

```
salario = horas * valorHora
```
